# FERRO Launcher

**An all-in-one desktop command center that unifies your applications, games, system folders, and CLI workflows into a single, native-speed launcher.**

Engineered with **Rust** and **Tauri 2.0**, FERRO eliminates the bloat of Electron-based launchers—delivering sub-5MB builds, near-zero idle CPU overhead, and under 50MB RAM usage wrapped in an **Obsidian Industrial** glassmorphic interface.

- **Unified Sectors:** Seamlessly switch between **The Forge** (dashboard), **Armory** (games), **Stack** (apps & utilities), and **Active System Folders**.
- **Rust-Powered Indexing:** Asynchronous filesystem scanning and instant process execution with memory-safe native bindings.
- **Command & CLI Palette:** Launch executables, open deep directory paths, or trigger custom shell scripts from a single search bar.
- **Obsidian Industrial UI:** Tactile dark-tungsten panels, asymmetric glassmorphism, and copper-amber telemetry accents.
